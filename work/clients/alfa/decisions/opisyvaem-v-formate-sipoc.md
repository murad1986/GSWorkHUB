# Описываем процессы в формате SIPOC и дорожек

Решение записывается с доказательством: `evidence` ведёт на событие, где оно
принято, а не на нашу же сводку. Решение без события — мнение, оформленное как
решение.

**Что решили.** Каждый процесс описывается двумя видами: SIPOC для границ и
дорожки для передач между ролями.

**Почему.** Клиент читает дорожки без обучения, а SIPOC удерживает границы —
без него описание расползается на смежные процессы.
